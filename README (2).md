# Нейрон әлемі — Биология, 9-сынып

Интерактивті сабақ сайты: нейрондардың түрлері мен қызметтері, глиальды жасушалар, миелинді және миелинсіз талшықтар, синапстар мен медиаторлар.

Оқу мақсаты: **9.1.7.1** жүйке жасушасының құрылысы мен қызметі арасындағы өзара байланысты орнату.

## Сайтта не бар
- 3D нейрон моделі (айналдыру, үлкейту, импульс анимациясы)
- Теория (6 бөлім)
- Симуляциялар: импульс жарысы, химиялық синапс
- 3 тапсырма (жеке, жұптық) дескрипторларымен
- 3 топқа арналған зияткерлік алаң
- Ойындар: «Иә/Жоқ» блиц, «Жұбын тап»
- А деңгейлі тапсырмалар, видео сілтемелер, рефлексия, үй тапсырмасы

## GitHub Pages-ке жариялау
1. GitHub-та жаңа репозиторий ашыңыз (мысалы, `neuron-alemi`), **Public** деп белгілеңіз.
2. **Add file → Upload files** арқылы `index.html` және `README.md` файлдарын жүктеңіз, **Commit changes** басыңыз.
3. **Settings → Pages** бөлімінде: *Source* — **Deploy from a branch**, *Branch* — **main**, қалта — **/ (root)**, **Save**.
4. 1–2 минуттан кейін сайт мына мекенжайда ашылады:
   `https://<сіздің-логиніңіз>.github.io/neuron-alemi/`

Сайт бір ғана `index.html` файлынан тұрады, қосымша кітапхана қажет емес (тек Google Fonts қаріптері интернеттен жүктеледі).
